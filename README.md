# DaggerPlayer

A private, Daggerheart™ Compatible character companion: a rules compendium, a guided character builder, and a live character sheet. Built with React + Vite + Supabase.

- Setup, environment variables and deployment: [docs/SETUP.md](docs/SETUP.md)
- Content packs (SRD 2.0 data, parser, validator): [docs/CONTENT.md](docs/CONTENT.md)
- License notes: [docs/LICENSE-NOTES.md](docs/LICENSE-NOTES.md)
- Plan and status: [docs/PROPOSAL.md](docs/PROPOSAL.md), [PROGRESS.md](PROGRESS.md)

```bash
npm install
npm run dev -- --host
npm test
```
