# Working rules
- The full spec is in PROJECT_BRIEF.md. Read it before any work.
- Follow the "How to work" steps in order. Stop and wait for my approval where the brief says to.
- Commit after each working stage with a clear message. Don't push broken builds to main.
- Run the dev server with `npm run dev -- --host` so Codespaces can forward the port.
- Use `npx supabase` for the Supabase CLI. Don't install it globally.
- Never commit secrets. Read keys from environment variables.
- Keep a PROGRESS.md file with what's done, what's next, and open rules questions.
